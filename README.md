# Mumbo's World - launch on Vercel

Unzip first. Upload all extracted files and the assets folder into a GitHub repository, with index.html at the top level.

Open https://vercel.com/new, connect GitHub, and Import your repository. Select Other for Framework Preset. Keep Root Directory at ./, leave Build Command blank (override if needed), and set Output Directory to . (a single period). No environment variables are required. Click Deploy.

Use the live .vercel.app address Vercel assigns. To connect mumbosworld.tv, open your Vercel project Settings > Domains and follow the DNS instructions shown there.

This export includes the latest sign enlargement and inward-wormhole fix. Upload the contents, not the ZIP itself.
